Data and portability

This prototype saves profile, tasks and experiments in your browser's localStorage. That means data is not synced between devices and can disappear if browser data is cleared.

For real commercial use, the next stage needs secure sign-in, cloud storage, privacy controls, backups, data deletion and proper security review.
